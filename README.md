A rotation showcasing all the pictures taken and uploaded by NASA on nasa.gov in a sort of screensaver engine

Things used for this project =

1. API key for nasa.gov
2. Uses data from nasa libraries
3. Requests library to connect to the server and fetch JSON data
4. JSON library to read, write, and save data after the script finishes
5. OS detector for better functionality
6. JavaScript for time and interactive buttons
7. HTML + CSS for screensaver design
8. Flash + Python for backend
9. Inspired screensaver design from the 'ambient mode' system in a Google TV
